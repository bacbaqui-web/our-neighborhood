# 도로 시설 참고 이미지 검토

사용자 요청: 한국에서 쓰이는 물건의 참고 이미지를 에셋백과에서 먼저 검토하고 승인 후 모델링한다.

- 기존 정적 에셋백과를 확장한다. 별도 React 앱이나 서버를 도입하지 않는다.
- 도로 시설 10개에 출처·국내 근거가 있는 후보 이미지를 등록한다. 국내 판매와 실제 국내 설치를 구분한다.
- 카드에 승인 체크, 교체 요청, 클립보드 이미지 붙여넣기, 파일 선택을 둔다. 교체는 재검색 요청이며 자동 검색 완료로 표시하지 않는다.
- IndexedDB에 이미지와 검토 상태를 함께 저장한다. 새 후보/직접 입력은 승인을 해제한다. 이 브라우저 저장임을 알리고 검토 내보내기로 제작자 전달을 지원한다.
- 이미지 없는 승인, 저장 실패, 손상된 기록, 과대/잘못된 이미지, 다중 탭 변경을 처리한다.
- 상태 전이·저장 실패 검사를 실행하고 Edge에서 붙여넣기/승인/교체/새로고침을 확인한다. 배포 후 공개 화면을 확인한다.
- 모델링은 이번 단계에 포함하지 않는다. 승인된 특정 이미지와 검토 기록을 확인한 뒤 시작한다.
