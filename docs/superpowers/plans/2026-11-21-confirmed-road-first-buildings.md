# 확정 도로 우선 건물 배치

요청: 도로 확정 후에는 건물이 도로를 피해서 생성되어야 한다. 이전 실제 윤곽 우선 규칙을 사용자 요청에 따라 변경한다.

구현: 확정된 차도·인도·통행 여유를 먼저 확보한다. 건물은 가까운 같은 편의 빈 공간(최대 30m)으로 이동을 시도하고 이웃 건물과 겹치면 이동 후보를 제외한다. 이동할 공간이 없으면 도로 밖에 남는 유효한 한 덩어리 윤곽으로 조정한다. 6㎡ 이상 공간도 없으면 생성에서 제외하고 알린다. 도로 폭과 연결을 건물 때문에 바꾸지 않는다.

데이터: 원본 sourceBuildingCollection은 보관하고 생성·편집 화면에는 조정된 buildingCollection을 사용한다. 조정된 윤곽으로 시야·건물 성격·주변 배치를 계산한다. 직접 지정한 입구 면은 이동량과 윤곽 변경에 맞춰 다시 대응시키며 층수·용도·디자인은 유지한다. 새 위치 선택에서 재생성할 때도 이전 편집 윤곽을 면 대응에만 사용한다.

검사: 이동 우선, 밀집 부지 축소, 중심선에 걸친 건물, 반복 생성에서 도로 유지, 이웃 겹침, 수동 입구 면 대응. 기존 건물 우선 겹침 검사는 새 정책으로 변경한다. 실제 장면 재생성과 공개 배포 화면을 확인한다.
