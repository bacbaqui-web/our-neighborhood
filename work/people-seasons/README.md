# 사람 사계절 의상

기존 10명의 봄 원본 30장을 보존하고 여름·가을·겨울 의상을 제작했습니다.
각 계절은 눈높이·30°·60° 시트 3장, 시트마다 8방향입니다. 전체 120장 / 960방향이며 새로 만든 그림은 90장입니다.

내장 image_gen으로 기존의 얼굴 생략, 머리, 체형, 얇은 선과 평면 채색을 유지했습니다.
눈높이 제작 기록은 generation.json, 높은 시점 60장의 입력·프롬프트·원본 경로·SHA256은 elevated/generation.json에 있습니다.
높은 시점은 해당 인물의 계절별 눈높이 옷과 기존 봄 30°·60° 그림을 함께 참조했습니다. PNG 픽셀은 후처리하지 않았습니다.

동네는 인물과 카메라의 높이 차이에 따라 눈높이·30°·60° 그림을 자동 선택합니다. 카메라를 내릴 때도 돌아오며, 경계에서 반복 전환되는 것을 막는 기존 여유 각도를 유지합니다. 실제 키와 발 위치는 기존 배치 기준을 유지합니다.
에셋백과에서는 인물을 클릭한 뒤 계절과 시점을 선택하고 해당 원본을 받을 수 있습니다.
계절 이미지는 처음 선택할 때 불러와 재사용합니다. 빠르게 바꾸면 마지막 계절만 적용하며, 실패 시 안내하고 다시 선택하면 재시도합니다.

재색인: `uv run --with pillow python work/people-seasons/package-elevated.py`
눈높이 원본 복사와 전체 재색인: `uv run --with pillow python work/people-seasons/package.py`
재현용 동네 확인 주소: `domestic-test/?location=original&radius=50&peopleView=1` (일반 화면에는 비교 버튼이 나타나지 않습니다.)

검사: 120장 파일·960프레임 경계·원본 해시, 10명 사계절 시점 상승/하강·발 위치·키·내보내기, 에셋백과 60장 브라우저 로딩, 실제 동네 여름·가을·겨울 30°/60° 및 눈높이 복귀를 확인했습니다.
화면 기록: verification/people-seasons/elevated-*.jpg 및 elevated-browser.json.
로컬 반영 상태이며 공개 배포는 하지 않았습니다.

공개 배포본: originals/에 새 PNG 90장을 보존하고, outputs에는 cwebp -lossless -exact로 인코딩한 WebP를 사용합니다. 90쌍의 RGBA 픽셀 완전 일치를 검사했습니다. 동네와 백과는 동일한 시점 목록을 사용하며 백과는 한 명을 드래그·방향키·버튼으로 회전합니다. 공개 백과 목록은 공개판에 실제 있는 모델을 기준으로 생성합니다.
