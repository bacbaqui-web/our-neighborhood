브이월드 건물 자료 — 2026-11-21

공개 사이트 https://magamiscom.ing/neighborhood/ 는 접속한 브라우저가 브이월드 2D 데이터 API의 LT_C_SPBD(도로명주소 건물)를 조회합니다. 이 Mac의 서버는 사용하지 않습니다.

순서: 선택 지점과 거리 → 여유 30m를 포함한 조회 범위 → 브이월드 건물 자료 → 기존 생성기 → 길 위 눈높이의 360도 시야 검사 → 건물·도로·소품 배치.

외부 응답은 allow-scripts만 허용한 별도 iframe에서 실행합니다. 같은 출처 권한이 없어 앱의 화면·저장소에 접근할 수 없습니다. 부모 화면은 iframe 창, null 출처, 요청 식별번호가 모두 일치하는 응답만 받습니다. 시간 초과와 취소 시 iframe을 제거합니다.

브라우저용 인증키는 사이트 실행에 필요하므로 방문자의 브라우저로 전달됩니다. 계정 비밀번호나 카카오 REST 키가 아닙니다. 원본 설정 파일은 공개하지 않습니다. GitHub Actions의 VWORLD_WEB_KEY로 빌드 시 vworld-config.json을 만들며, 원본 저장소에는 키 값을 넣지 않습니다. 등록 URL은 https://magamiscom.ing/neighborhood/ 입니다. 현재 개발키 만료일은 2027-05-21이며 만료 전에 갱신해야 합니다.

도로명주소 건물의 모양·지상 층수·관리번호를 사용합니다. 용도·지하층·실측 높이가 모두 제공되는 자료는 아닙니다. 지상 층수가 없으면 1층으로 추정하고 floorsEstimated에 표시합니다. 외관과 용도 배치는 기존 추정 규칙을 사용합니다. 새 자료를 받았다고 실제 건물 외관과 동일하다고 판단하면 안 됩니다.

한 번에 1,000개씩 최대 6페이지를 조회합니다. 중복 식별번호는 제외하며 중간 페이지가 실패하면 일부 자료로 성공 처리하지 않습니다. 주소·시야가 같아도 이전 ESRI 자료로 만든 장면을 새 자료의 결과로 재사용하지 않습니다. 사용자가 저장한 이전 장면은 삭제하지 않습니다.

로컬 개발에서는 /api/buildings가 키를 보관하고 조회합니다. 공개 경로에는 로컬 주소나 이 API가 필요하지 않습니다. 공개 빌드는 VWORLD_WEB_KEY가 없으면 중단합니다.
