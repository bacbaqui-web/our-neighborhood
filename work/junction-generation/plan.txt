교차로 자동 생성 적용 / 2026-11-22
목표: 확정 도로의 연결·폭·보도를 공유하여 혼합 등급 교차로를 만들고 공개 생성 장면을 검토한다.
선택: 완성 사거리 GLB를 늘여 붙이지 않는다. Python의 확정 도로 면에서 교차부·횡단·연석·선 종료를 계산하고 등록된 부품의 제작 규격/원본을 재사용한다. 정형 평지 예시는 도감용으로 유지한다.
범위: 신규 브라우저 생성과 재생성, 수동 도로 등급 보존. 이전 저장 결과는 자동 변조하지 않음. 360도 가림 규칙 유지.
작업:
1. 혼합 등급 T/십자/사선/입체교차/경사/협소 보도 회귀검사.
2. work/junction_generation.py: 실제 중심선 연결, 공유 도로 경계, 지형 맞춤 표시·연석·턱낮춤/점자 배치. 기존 arterial과 교차부 면/표시 소유권을 분리.
3. road-context 렌더러에서 매개변수 부품 및 등록 부품 표시. 생성 entry/pack 연결. 상가·소품의 교차부 통로 침범 제외.
4. 실제 입력 동네 생성, 로컬/공개 장면 검사. 한 검토 에이전트가 결과 보고서를 작성하면 root가 재현·판정하고 통합 지침의 부족한 규칙만 보완.
완료: 관련 검사/소스 묶음/빌드, main 배포 성공, 공개 동네 장면, 검토 보고와 root 판단 기록. 추정 교통 통제는 사실처럼 표시하지 않음.
