생성 전 지도 정돈 — 로컬 구현 계획
범위: 기존 도로 설정을 도로 → 건물 두 단계로 교체. 사용자 요청에 따라 공개 배포·main 병합 보류.
구현: 기존 HTML/SVG 화면과 Python 배치 규칙 재사용. 새 UI 라이브러리를 도입하지 않음.
1. 도로 확정·건물 위치/용도/입구를 미리 계산하는 공통 함수를 분리하고 생성과 공유한다.
2. 기존 도로 선택 묶음을 유지하며 등급 색상, 클릭 설정창, 휠 확대 및 지도 이동을 제공한다.
3. 건물 평면 미리보기, 높이 없는 360도 직선 가림 예상, 용도·입구 수정과 충돌 없는 위치 이동을 연결한다.
4. 원본·수동값 보존, 취소, 재시도, 단계 이동, 실제 생성 전달을 시험한다.
완료: 관련 Python/JS 회귀 검사, 패킹 일치, 로컬 Edge 상호작용과 생성 결과 확인. 공개판은 그대로 둔다.

검증 기록
- 분리된 브랜치: codex/map-preparation-local (기준 3ec004bc62ad).
- Python 관련 58개 및 전신주 회귀 5개 통과. JS 도로 선택·저장·생성 작업·VWorld·번들 검사 통과.
- 전체 정적 빌드: 1692개 파일, 972.4 MB. 공개 배포하지 않음.
- 실제 825동의 기준 도로·정면 결과를 이전 함수와 비교해 동일함을 확인. 네이티브 Python 측정 3.816초 → 1.726초. 브라우저 전체 생성 시간 비교가 아님.
- 최종 생성 중 도로 면과 선이 섞인 GeometryCollection에서 전신주 경계를 읽지 못한 오류를 재현하고 수정함. 실제 생성 재검사 결과는 PROJECT_STATE.json 참조.
- 정돈 설정으로 실제 21동 생성·저장·Edge 3D 표시 성공. 주거 용도·입구 8번 면·동쪽 약 4.97m 이동이 최종 자료에 유지됨. 가게 조회는 실패하여 건물·도로 자료만 사용함.

후속 수정 — 이동·인도·삭제·충돌·입구
- 이동 실패를 원위치 복귀로 처리하던 방식 대신 충돌 초안을 보존하고 실제 겹침 면을 표시한다. 최종 생성은 충돌이 남으면 거부한다.
- 도로가 같으면 이동 계산에서 도로 재배치를 재사용한다. 보행/1차는 추가 이격 없이, 2차 이상은 실제 인도 면까지 함께 계산한다.
- Delete/Backspace는 원본 보존 제외 처리. 외벽 면 번호 클릭으로 입구 이동.
꼭짓점 검토: 정릉동 자료 825동, 중앙값7/최대76, 16개 초과32동/32개 초과7동. 0.05/0.2/0.5m 단순화에서 총 꼭짓점6581→6304/5946/5174, 최대 대칭차 면적 비율0.41/2.36/6.73%. 권장: 개수 상한 대신 작은 오차 내 일직선 점 정리. 실제 단순화는 미적용.
- 후속 검사: 지도 정돈15개·도로48개·기존 편집6개 Python 검사 통과. JS 선택/편집/정돈/생성/번들 검사 통과.
- Edge에서 외벽12번 클릭, 건물 끌기, 빨간 도로/건물 겹침2곳 및 생성 비활성화, Backspace 건물 삭제, Delete 도로 삭제 확인. 생성 입력에 excludedRoads 및 deleted 유지, 편집 지도에서 해당 건물 제외 확인.
- 실제825동에서 이동 캐시와 전체 재계산의 용도·입구·충돌 수 일치. 네이티브 캐시 계산0.452초(브라우저 시간 아님).
- 후속 실제 생성·저장41동 성공. 삭제한 건물/도로가 최종 건물/도로 자료에 없는 것을 확인. 미해결 도로충돌0, 수치 오차 수준 교차 면적 도로0.0000036㎡/인도0.0000001㎡.
- 최종41동 Edge 3D 화면 표시 확인. 최신 전체 빌드1692파일/972.4MB 통과. 별도 로컬 브랜치 유지, 공개 미배포.
