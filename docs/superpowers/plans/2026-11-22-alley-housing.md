# 1차도로 주택 구성 구현 계획

사용자 2026-11-22 요청을 설계 기준으로 적용한다. 기준 폴더/main을 사용하고 다른 대화 변경을 보존한다. 기존 담장·대문·셔터·나무·필로티 모델을 재사용한다.

- [ ] 1. 도로에 직접 접한 주택의 방향과 직사각형 여부로 detached / piloti / old-villa를 결정한다. 틀어진 주택은 붉은 벽돌 2층, 나머지는 단층 기본값 제외. 수동 지정과 특수 용도는 보존한다.
- [ ] 2. 기존 부지 생성에 분류 연결. 단독주택 마당의 주차 제거, 도로 평행 담장·대문과 나무 배치. 빌라 도로측 담장. 좁은 틈 철문, 온전한 한 대 공간을 확보한 넓은 틈은 닫힌 셔터.
- [ ] 3. 대표 윤곽/모퉁이/공간 부족/수동 편집 회귀 검사, 생성 묶음 검사, 실제 장면 확인.
- [ ] 4. 해당 파일만 main에 커밋·공개 배포하고 공개 화면 확인.

수치: 도로 평행 오차 5도, 직사각형 윤곽 단순화 3cm·면적 일치 99.5%, 담장 1.8m, 대문 1.2m, 차고 최소 2.6×5.2m. 공간 부족은 QA에 명시하며 건물·공공 통로 침범으로 해결하지 않는다. 필로티 계단실과 구조 기둥·주차가 맞지 않는 윤곽도 미지원으로 기록한다.
검사: tests/test_alley_housing.py, tests/test_scene_edits.py, 기존 scene editing/road priority 검사, pack --check, 공개 필수 검사. 기존 360도 생성 범위를 유지한다.
