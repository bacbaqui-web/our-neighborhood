# 여러 도로 구간 묶기

요청: Shift 클릭으로 여러 구간을 선택하고 하나의 도로로 묶어, 다음 선택과 등급 변경을 함께 처리한다.

변경 범위: 생성 전 도로 설정과 생성 후 도로 수정이 같은 선택 모델을 사용한다. 기존 editId와 도로 모양을 보존하고 sceneEdits.roadGroups에 겹치지 않는 구간 ID 묶음을 저장한다. 묶음 생성은 등급이 같을 때만 가능하며 혼합 등급은 사용자가 먼저 통일한다. 해제는 등급을 유지한다. 자동 복원은 선택한 구간의 수동 등급과 묶음을 해제한다. 건물 수동 정보는 보존한다.

완료 조건: Shift 추가/해제, 묶음 재선택, 전체 등급 변경, 취소와 해제, 저장 후 복원, 재설정 시 ID 보존을 검사한다. 실제 장면에서 저장·재생성·재열기를 확인하고 공개 배포 후 화면을 확인한다.

검사: tests/road-selection.mjs, tests/test_road_groups.py 및 기존 도로/생성 검사. 로컬 50m 검사 장면에서 1번과 10번 구간을 묶어 저장·재열기 후 함께 선택되는 것을 확인했다. 다른 작업의 Codex 연결 변경은 이 배포에 포함하지 않는다.
