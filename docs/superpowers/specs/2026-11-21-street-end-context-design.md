# 길 끝 원경

사용자가 실제 지도 건물을 단순하게 표시하는 첫 번째 방식을 승인했습니다. 가까운 시야 선택과 상세 모델은 유지하고, 길 너머의 실제 건물 윤곽·층수로 단순한 벽과 지붕만 만듭니다. 임의의 실루엣은 사용하지 않습니다.

건물 조회를 한 번에 묶어 상세 반경 +150m(최소200m)까지 받습니다. 원경 전용 재조회와 2km 전체 조회는 하지 않습니다. 기존 도로 타일에서 같은 범위를 사용합니다. 원경은 최대256동이며 가림 검사 후 가까운 순으로 선택합니다. 상세 생성기에 전달하는 건물은 기존 범위를 유지합니다. 도로는 원경까지 이어지고 건물 바닥과 겹치지 않게 잘라냅니다.

원경은 창문·소품·텍스처를 추가하지 않고 면 색과 현재 조명으로 표현합니다. 실제 윤곽을 사용해 사각형 근사로 길을 막지 않습니다. 원경 건물과 도로는 각각 합쳐 그리며 바닥 높이를 공유합니다. 새 생성 결과의 캐시를 기존 결과와 구분합니다.

확인: 상세 건물 중복 없음, 도로 연결·빈틈·겹침, 경사 접지, 낮밤 색, 추가 삼각형과 자료 처리 시간, Edge 실제 화면. 공개 반영은 검증한 변경만 포함하고 기존 Codex 시험판 작업은 보존합니다.
