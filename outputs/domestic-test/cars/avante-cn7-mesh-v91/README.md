# CN7 단색 저폴리곤 메쉬 · v91

차량 전체: **1,978 삼각형**. 기존 v90 59,634개에서 약 96.7% 줄였습니다.
GLB는 18개 메쉬 프리미티브와 10개 단색 재질을 사용합니다. 이미지 텍스처는 없습니다.

- 고해상도 차체의 음영 법선을 저폴리곤 차체에 전사
- 차체 윤곽에 440개, 지붕·필러에 178개 삼각형 배분
- 네 바퀴의 위치·직경·최저점 유지, 타이어를 16분할로 단순화
- 가는 패널 이음선은 원통형 곡선 대신 얇은 리본 메쉬 사용
- 유리·램프·그릴의 내부 분할 축소 및 차체 간섭 보정
- 휠의 볼트·브레이크 디스크, 작은 엠블럼·가느다란 크롬 장식 생략
- GLB의 작은 부품은 같은 재질끼리 병합; Blender 원본은 부품별 편집 가능

`avante-cn7.blend`는 편집 원본, `avante-cn7.glb`는 런타임 모델입니다.
`qa.json`에는 실제 GLB의 삼각형 수, 정점·법선, 재질과 네 바퀴 접지 검사 결과가 있습니다.
`panel-qa.json`은 부품 병합 전에 71개 패널의 442개 삼각형 중심에서 차체 간섭을 검사한 결과입니다.
