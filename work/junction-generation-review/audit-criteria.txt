자동 생성 교차로 독립 검토 준비 / 2026-11-22
상태: 적용 전 감사 기준. 생성 결과를 아직 받지 않았으므로 최종 판단 아님.

사용자 요청
- 확정 교차로 지침과 부품을 실제 동네 자동 생성에 연결.
- 등급이 다른 도로의 접속을 확인하고 공개 화면 확인.
- 생성 결과의 문제를 찾아 지침 수정 제안과 함께 독립 보고.

검토 순서
1. 증거의 범위: 소스 커밋·생성 입력·생성 장면 ID·공개 URL·공개 실행·스크린샷 구분. 예시 GLB가 열리는 것만으로 생성 통합을 인정하지 않음.
2. 연결 관계: T/십자/비직각·1-2/1-3/1-4/2-3/2-4/3-4의 실제 검사 범위 기록. 교차하지 않는 입체교차·보행 전용·막다른길이 합쳐지지 않는지.
3. 동일 도로 연속성: 자료 분할 경계에서 폭·등급·선이 반복 초기화되거나 조립 모델이 덧씌워지지 않는지. 수동 묶음과 수동 등급 유지.
4. 평면: 차도 틈·중복 면·모서리 침범, 큰길 본선과 작은길 접속부, 보도폭 독립성. 부품을 늘여 선폭·점자 돌기·연석 높이가 왜곡되지 않는지.
5. 높이: 모든 접속점/경사면·경계높이 연속, 경사판 앞뒤 단차, 지형을 뚫거나 공중에 뜨는지. 1.5cm 단차는 완전 무단차와 구분.
6. 노면 표시: 중앙선/차로선/가장자리선 역할 분리, 정지선→횡단보도 순서, 모서리·유도선·기존 arterial 표시 중첩, 근거 없는 회전 허용/버스차로 생성 금지.
7. 보행 연결: 횡단부 양끝에 실제 보행 공간 존재, 높은 연석과 분리대가 입구를 막지 않음. 기둥·가로수·차량·담장 등 후속 생성물이 예약된 통로를 다시 막지 않음.
8. 생성 제한: 현재 관찰점 360도 시야 유지, 건물 도로 우선 규칙 유지, 실정보/수동편집 우선, 기존 저장 동네의 처리 방식.
9. 부품 사용: registry 등록 ID/삭제 상태 존중, 새 부품 사용과 절차적 재생성 구분, 3종 완성 예시를 실제 교차로 위에 고정 도장처럼 얹지 않음.
10. 시각 검증: 공개 실제 생성 장면 눈높이와 위쪽 시점, 최소 경사 사례, 부품/기존 시설 겹침. 자동 수치 통과가 실제 화면 검증을 대체하지 않음.

기존 경로의 주의 지점(새 구현 결함을 뜻하지 않음)
- work/arterial_plan.py가 별도로 교차 횡단보도, 모퉁이 연석, 턱낮춤, 점자 표시를 생성함. 새 구현과 소유권/제외 영역 합의 필요.
- 기존 arterial의 리더 중심 정렬·baseHalf는 다른 등급의 병행 도로와 접속 단면을 과도하게 통일할 여지가 있어 검사 필요.
- 기존 mouths 횡단 표시 루프에는 모든 실제 보행공간 접속을 증명하는 자료가 없으므로 새 결과의 후보/제외 조건 확인.

보고서 구분
A. 생성 결과에서 재현한 구현 오류: 위치/장면/캡처/수치와 기대·실제 명시.
B. 지침 빈틈: 현재 문구로 판단이 모호한 경우만 수정안 제시.
C. 검증 한계: 화면/데이터 없어서 확인 못 한 항목. 추정 결함으로 단정하지 않음.
D. 주 에이전트 확인란: 채택/기각/보류와 재검사 근거를 별도로 기록하도록 전달.
