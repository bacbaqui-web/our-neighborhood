검사 범위
- 제작 목록 → 공통 에셋백과 registry → 실행 경로를 구분해 확인했습니다.

확인 결과

1. 1차도로 소품 8종
- grade1Assets 8종은 raw catalog에 일부가 없더라도 remakes.js가 등록부에 추가합니다. 따라서 실제 백과 누락이 아닙니다.

- security-lamp: streetlights.js → grade1-street/models.js createSecurityLamp. 등기구는 같은 제작 모델과 grade1:security-lamp ID를 사용합니다. 공간별로 크기를 임의 확대하지 않고 팔 길이와 부착 높이를 조정합니다.
- 발견/수정: 보안등 직접 생성 경로가 백과의 삭제 반영 상태를 무시했습니다. curation의 삭제 상태에서 등기구와 조명 소스를 함께 제외하도록 수정했습니다. 수정 전 회귀검사에서 1개가 남아 실패했고 수정 후 0개로 통과했습니다.
- 주택·담장 조사 보고서는 원래 보고서 요청 범위입니다. 그 보고서의 규칙이 자동 생성기에 반영됐다는 뜻은 아닙니다.

2. 교차로 부품 12종

- 연석·경사판·표시는 고정 GLB를 늘여 붙이는 것이 아니라 실제 도로 표면에 맞춘 매개변수 형상입니다. 점형 점자블록은 같은 factories 모델을 실제 치수 그대로 배치합니다.
- curb-corner, tactile-guidance, median-end, turn-guide 및 조립 예시 3종은 참고 전용입니다. 실제 시설·방향·연결 정보 없이 무작위로 놓아서는 안 됩니다.
- 발견/수정: manifest와 백과 설명이 모두 '자동 동네 배치 미적용'으로 남아 있었습니다. manifest를 5개 실행 연결/7개 참고 전용으로 나눴습니다. catalog 설명 동기화는 주 담당자가 처리합니다.
- 재발 원인: build-asset-encyclopedia.mjs 원래 코드가 junction manifest를 읽지 않아 재생성 시 junction: 고정 ID가 file: 보관 ID로 바뀝니다. 주 담당자에게 builder 수정 필요를 전달했습니다.

해석 주의
- 등록과 자동 배치는 같은 뜻이 아닙니다. 자동 배치는 사용 조건과 실제 생성 결과가 있어야 확인됩니다.
- 백과 builder를 다시 실행한 뒤 고정 ID 재고 검사를 해야 '만들었다가 재생성하면서 사라지는' 문제를 막을 수 있습니다.
- 다른 진행 중 변경, 오래된 실험 파일, 이미 승인되지 않은 교체 후보를 이번 검사만 근거로 배포하거나 활성화하지 않습니다.
