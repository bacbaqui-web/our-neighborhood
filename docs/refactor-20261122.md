# 우리동네 전체 감사와 구조 정리 결과 — 2026-11-22

로컬 코드에서 **우리동네의 지도 분석·배치**와 **에셋백과의 모델 제공** 경계를 실제로 분리했습니다. 검사와 승인 자료를 확인하여 불필요 캐시를 삭제했고, 정식 공개 파일은 명시적 목록으로 제한했습니다. 실제 Python 기하 검사, 선택 변경 커밋, 공개 배포와 Edge 공개 화면 확인까지 완료했습니다. 공개 검사 중 발견한 기존 다중 도형 오류도 수정하고 같은 지점에서 재검사했습니다.

[초기 전체 감사](file-audit-20261122.md)는 정리 전 스냅샷입니다. 현재 구현 경계는 [실행 구조](runtime-architecture.md)를 참고하세요.

## 구현과 정리

- 정식 Python 생성 13개 모듈은 `work/neighborhood-generation`으로 이동했습니다. 기존 실험 폴더의 진입점은 얇은 호환 파일이며 브라우저 묶음은 새 정식 구현만 포함합니다. 12개 원본은 내용 해시 일치, 나머지 1개는 로컬 증거 파일 탐색 경로만 조정했습니다. 생성 중 모듈 캐시를 격리하고 실패 시 상태 복원을 검사합니다.
- 실제 house 외벽·창문/문·텍스처와 nature 크기/형상 구현은 에셋백과가 소유합니다. 모델 제공을 7개 분류 provider로 분리하고, 동네 배치/visibility 의존을 제거했습니다. UI의 완성 건물/거리 예시만 preview 조립 어댑터를 명시적으로 주입합니다. 기존 공개 URL은 재수출/호환 어댑터로 유지합니다.
- 69개 모델 소스의 소유권과 역방향 의존을 검사합니다. 고정 ID, 모델 바이너리, 출처와 승인 자료는 보존했습니다. 오래된 상점 참고이미지 검사는 기본 18개와 추가 50개의 실제 계약·승인 유지/초기화 조건으로 갱신했습니다.
- 공개 입력 1,594개는 `config/publication-files.json`에 명시했습니다. Git index나 출력 폴더의 임의 파일이 자동 포함되지 않습니다. 누락·중복·경로 탈출·심볼릭 링크·raw Python·캐시를 거부하고 2,183개 런타임/등록 에셋 참조를 검사합니다.
- 확인된 캐시 1,114개, **372,285,206 bytes**를 삭제했습니다. QA 프로필의 IndexedDB/Local Storage, 실제 사용자 저장 동네, 원본/승인 증거, 설치 환경, 재생성 비용이 큰 복구 캐시는 보존했습니다. 보호 대상 8,742개 해시 차이는 0이었습니다.
- 이번 감사에서 만든 inventory 3개는 gzip으로 압축했습니다. 압축 해제 SHA-256이 원본과 같음을 확인한 뒤 원 JSON을 제거하여 **49,060,731 bytes**를 줄였습니다. 검사를 위해 만든 임시 fixture와 임시 venv도 제거했습니다. hard link가 포함된 fixture의 논리 용량을 실제 확보 디스크 용량으로 합산하지 않습니다.

### 공개 생성에서 발견한 기존 오류

첫 공개 배포 후 안국역 신규 생성에서 `work/arterial_plan.py:199`의 `MultiPolygon.exterior` 오류가 실제로 발생했습니다. 이 파일은 리팩토링 이전 a2391da와 같았습니다. `tests/test_arterial_crosswalks.py`는 실제 큰길 생성 전체를 합성 공공면으로 실행해 같은 실패를 재현합니다. 지도·지형의 외부 조회만 고정 입력으로 대체합니다. 수정은 단일 외곽선으로 표현할 수 없는 끊긴 면·빈 면·구멍 후보를 건너뛰고 `qa.skippedCrosswalks`에 ID·사유·도형 종류를 기록합니다. 정상 횡단면은 기존 면적/범위를 유지합니다. 이는 미지원 횡단부를 완성 처리하거나 주변 교차로 규칙 전체를 바꾸는 수정이 아닙니다.

관련 3개 회귀검사와 정식 CI·교차로·참조 검사 28개 명령이 통과했습니다. 수정 커밋은 `bce9d8c`이며 동일 안국역 지점의 공개 신규 생성이 끝까지 완료됐습니다.
