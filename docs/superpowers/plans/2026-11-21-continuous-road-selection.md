# Continuous road selection Implementation Plan

**Goal:** 기준점 주변만 보여 주고 교차로를 지나 직진하는 길은 한 번에 수정합니다.
**Scope:** work/road_sections.py의 방향별 연결, road-setup.js와 road-map.js의 표시 범위, 통합 지침과 저장 호환성. 다른 작업은 보존합니다.
**Decisions:** 화면과 목록은 기준점 100m(입력 범위가 작으면 그 범위) 안에 닿는 길만 표시합니다. 원본 전체는 생성에 넘깁니다. 연결 방향 차이 35도 이하이고 차선 후보와 12도 이상 차이 나는 상호 최선 연결만 묶습니다. 이 수치는 기하학적 판별 허용값이며 법적 도로 기준이 아닙니다. 실제 차로·보행 여부·수동 지정 범위는 경계로 유지합니다. 기존 일부 구간의 수동 등급을 자동 구간까지 확대하면 건물 충돌이 생기는 실제 사례를 확인했으므로 기존 수동 범위는 확장하지 않습니다.

- [x] 기존 교차로별 분할·추정 등급 차이·수동 경계 테스트의 실패를 재현.
- [x] 직진 연결, 갈림길·차로·층·수동 지정 보존 검사 및 가까운 도로 필터 구현.
- [x] 실제 지도에서 범위 축소·길 전체 강조·분기 독립 편집을 확인.
- [x] 독립 검토와 필수 검사 후 공개 배포, 공개 화면 확인 및 상태 기록.
