교차로 지침 독립 검토 취합 기록 — 2026-11-22

범위: 교차로 지침과 직접 연결된 공통 제작·배치 규칙
방식: 세 에이전트가 서로의 결과를 보지 않고 검토 → 주 에이전트가 근거와 중복을 확인해 취합 → 세 에이전트가 통합 문구 재검토

현재 규칙의 수정 원본: docs/project-guidelines.txt J01~J11
이 파일은 검토 증거이며 별도 제작 지침이 아닙니다.
검토 시작본: 1ddf3c2 기반 작업 문서. 기존 미커밋 12절은 보존했으며 이번 수정에 포함하지 않습니다.

에이전트 1 · 논리와 우선순위
통합 지침과 50개 후보 목록을 독립 대조했습니다.
- 양쪽 경사판 일률 요구를 횡단 유형별 조건으로 바꿀 필요
- 노란 가장자리선 명칭과 선 역할 구분의 충돌
- 등급 변경이 실제 폭·국소 차로·통행 제한까지 덮어쓰는지 불명확
- 실제 관찰 장애물 보존과 추정 통로 확보의 적용 범위 구분 필요
- 보고서 번호와 백과 고정 ID·이미지 승인 기록의 구분 필요
재검토: 수정안을 다시 읽고 중요한 잔여 충돌이 없음을 확인했습니다.

에이전트 2 · 기하와 조립
교차로·보행 연결·부품 계약을 검토했습니다. 실패 예는 합성 검사 제안이며 실제 버그 재현 결과가 아닙니다.
- 확인된 시설을 공간 부족만으로 조용히 생략하지 않도록 처리 분리
- 양끝 보도 포함 여부보다 기존 보행로까지의 연속 통행 검사 필요
- 입체·예각·엇갈림·다지·교통섬과 인접 접속부의 지원 범위 명시
- 경사판 양옆 전이·최종 삼각면·추가 지지점 검사 필요
- 차체 회전 점유·유도블록 종단·배수 간섭·부품 단면 계약 보완
- 공통 임시 부품으로 필수 연결 실패를 성공 처리하지 않도록 예외 명시
재검토: 수정안에서 중요한 새 모순을 찾지 못했습니다. 생성기 실행 검증은 하지 않았습니다.

에이전트 3 · 교통시설과 근거
신호·표지·노면표시·카메라를 검토하고 2024년 별표 6 원문을 대조했습니다.
- 차도 가장자리선과 주정차 제한선의 명칭 분리
- 무단차·고원식 횡단의 경사판 예외 필요
- 보호구역 횡단과 안전지대의 색상 선택 근거 보완
- 장식 문자 생략 규칙에서 교통표지의 필수 문자·숫자·기호 제외
- 교차로 단위 점등 일치와 실제 운영 미확인 상태 구분
재검토: 수정안에서 새로운 오류나 미반영된 중요한 문제를 찾지 못했습니다. 최신 법규 적합성 검증은 아닙니다.

취합한 결정 12건
- 횡단 형식 [J05]: 양쪽 경사판을 일률 요구 → 무단차·고원식·교통섬 형식에 맞춰 필요한 접근부만 구성
- 시설 보존 [J05]: 공간 부족 때 확인 시설까지 생략 가능 → 추정 시설은 이유를 남겨 생략, 확인·수동 시설은 원본 보존과 미완성 진단
- 도로 등급 [도로 분류·J02]: 차선/차로 혼용과 등급 수정 범위 불명확 → 전체 차로 수로 통일하고 지정한 항목만 변경
- 연결과 복합 접속 [J03·J04]: 정형 교차 중심, 높이·중복 영역 조건 부족 → 연결 근거와 층을 확인하고 비정형·미지원 형식을 분리
- 보행·차량 공간 [J05·J09]: 양끝 보도나 중심점 검사로 오해 가능 → 연속 보행로·실제 외형·회전 점유·상부 공간 검사
- 경사·유도·배수 [J06]: 접지 끝점만으로 충분하다고 오해 가능 → 양옆 전이·최종 면·지지점·유도 종단·배수 간섭 확인
- 선과 색 [J07]: 노란 가장자리선으로 역할 혼합, 색 조건 누락 → 선 역할 분리, 보호구역·교통 분리 방식별 도안 근거 확인
- 신호·표지·문자 [J07·J08]: 개별 부품의 방향·점등·문자가 어긋날 수 있음 → 접근부 공통 기준과 교차로 단위 점등, 교통 의미 문자 보존
- 관찰 장애물 [J09]: 보존과 비우기의 예외 관계 불명확 → 실제 관찰 충돌은 기록하고 생성 기본값에 복제하지 않음
- 부품·이미지 승인 [J10]: 연결점만 있거나 보고서 번호가 승인처럼 해석될 수 있음 → 단면·접선·변형 범위 계약과 백과 ID별 이미지 승인 연결
- 완료 검사 [J11]: 몇 장면의 통과가 전체 지원처럼 해석될 수 있음 → 지원·미지원·미검사 표본과 문서/구현/공개 상태 분리
- 법정·제품 수치 [J01·J07]: 특정 판본·제품·추정값의 일반화 가능 → 출처·시점·확인 범위를 기록하고 미확인 최신 수치는 보류

확인 범위와 제한
- 이번 작업에서는 교차로 생성기와 3D 모델을 수정하지 않았습니다. 새 조건의 구현·실행 검증은 별도입니다.
- 최신 법정 치수·이격·설치 높이·점자블록 유효폭 및 현장 신호 운영은 확정하지 않았습니다.
- 예각·엇갈림·교통섬·복합경사 등 제안 사례는 검사할 조건입니다. 이번 검토에서 모두 생성해 통과한 사례가 아닙니다.
- 세 검토자가 수정안에서 중요한 잔여 충돌을 찾지 못했지만 모든 현장·법규·미지원 형식에 대한 무오류를 보증하지 않습니다.
