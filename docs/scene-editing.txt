도로·건물 편집 검사 기록 — 2026-11-21

통합 규칙은 docs/project-guidelines.txt 9절을 따릅니다. 이 문서는 구현과 검사 기록입니다.

작동 경로
Shift + 클릭 → 네이티브 대화상자 → 원본 입력과 scene-edits.json 병합 → 기존 Worker 생성기 → IndexedDB에 완료 결과 저장 → 같은 동네 재표시.
도로 변경은 접한 도로를 다시 선택하고 미확인 층수·용도·외관·정면 및 주변 배치를 다시 계산합니다.
수동 건물 설정은 유지합니다. 자동 설정으로 복원은 원본과 규칙으로 돌아갑니다.
실제 건물 윤곽은 유지하며 폭 추정이 겹치면 도로 표면을 조정합니다. 중심 통행 공간 충돌은 저장하지 않고 오류를 알립니다.

구현 기본값 (실측·법정 기준 아님)
차도/인도 한쪽 폭: 1차 5.2/0m, 2차 7.1/1.5m, 3차 13.5/3m, 4차 19.9/4m.
미확인 층수: 면적에 따라 1·2차 최대4층, 3차 최대8층, 4차 최대16층. 확인된 층수는 유지합니다.
도로 등급과 무관하게 실제 용도가 주거이면 주거로 유지합니다. 교회·주유소 등을 면적만으로 추정하지 않습니다.

검사
Edge 로컬 솔매로17가길 시험 장면: 1→2차도로 재생성, 건물 층수6·적벽돌·오래된 연식·입구면29 저장과 재열기, 도로 변경 후 유지.
중심 통행 공간과 건물 충돌 오류: 저장된 장면 유지, 대화상자에서 재시도 가능.
비어 있는 가로등 목록의 기존 렌더 오류를 재현해 수정하고 회귀검사 추가.
윤곽 정점 순서가 뒤집혀도 같은 물리적 입구 면이 유지되도록 좌표 기반 재대응 검사.
뒤편 건물이 가려진 큰길을 기준으로 삼지 않는 사례, 실제 층수·용도 보존, 미확인 층수 자동 변경 검사.

범위
입구는 벽면 단위 선택입니다. 벽 위에서 세부 위치를 끄는 기능은 아닙니다.
상가·입구 배치는 접근 공간과 형상 조건을 통과할 때 생성합니다.
현재 변경 시 기존 장면을 다시 계산하므로 즉시 끝나지 않습니다. 계산 중 취소할 수 있습니다.
정류장·전철 출입구·버스전용차로는 도로 등급만으로 새로 만들지 않습니다.
1~4차 대표 모든 지역의 풍경 세부 규칙 완성으로 확대하지 않습니다.
공개 배포 결과는 PROJECT_STATE.json에 기록합니다.

중간 배포의 업로드 파일 조회 오류는 후속 최종 배포 성공으로 해결했습니다.

입구 주변 지도·건물 외형 미리보기 — 2026-11-21
입구 평면도에 주변 도로·인도·이웃 건물 윤곽, 북쪽과 축척을 표시합니다. 벽면을 누르거나 입구 방향 목록으로 고릅니다. 가까운 벽면을 선택해 짧은 면의 클릭 영역 중첩을 줄입니다.
미리보기는 선택한 원본 건물의 실제 윤곽·중정·여러 동과 입력 층수·디자인·입구 면을 반영합니다. 선택한 입구를 향해 카메라가 시작하며 회전·확대할 수 있습니다. 명시 디자인이 없는 주택의 연식 변경은 생성기와 같은 외관 선택 규칙을 따릅니다.
부지·주차·상가 입구는 적용 후 주변 공간과 함께 계산되므로 외형 미리보기에는 포함하지 않습니다.
로컬 Edge: 주변 지도 표시, 층수6→4·석재 디자인 변경, 목록과 지도에서 입구 변경 및 미리보기 갱신 확인. 실제 윤곽·여러 동·층수·공유 렌더러·입구 표시 회귀검사 및 기존 에셋/편집 검사 통과.
