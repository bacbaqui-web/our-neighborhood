# 상가 갤러리 구현 계획

Goal: 승인한 갤러리와 상세 편집 구성을 기존 정적 백과에 구현하고 공개 검증한다.
Architecture: 기존 뷰어·모델 제공자를 재사용. 별도 상세 모듈과 검증 가능한 브라우저 저장 모듈. 배치 기본값은 assembly-rules 소유, 편집값은 적용 전 초안.
Spec: 사용자 승인 — 조립 갤러리, 지침, 사용 에셋, 크기 시험, 배치 조건, 레퍼런스, 수정 요청.

- [ ] 계약과 저장: shop-profiles.js, shop-workspace.js. 유효 범위·중복 저장 충돌·잘못된 저장 자료·실패 표시 검사.
- [ ] 화면: shop-gallery.js/css, app.js 연결. 기본 갤러리와 개별 에셋 전환, native dialog, 실제 조립 결과의 부품 수량과 제외 이유, 네 가변 모델과 고정 편의점 구분.
- [ ] 지침·근거: 기준 지침에서 공개 발췌 생성, 기존 사진·출처 재사용. 브라우저 저장 범위 명시와 JSON 내보내기.
- [ ] 검사·배포: 크기 경계·저장 재열기·취소·다른 분류 회귀, 원격 깨끗한 빌드, 공개 화면.

Review Focus: 비동기 모델 경합/해제, 저장 오류와 타 탭 충돌, 좁은 화면, 지원하지 않는 크기, 미저장 입력 유지.
No new framework: 기존 vanilla UI/스타일 유지, React Astryx 설치는 이 화면에 불필요한 이행이므로 구조 지침만 참고.
