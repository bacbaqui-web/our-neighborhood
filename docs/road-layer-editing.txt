도로 목록 편집 — 2026-11-22

- 도로 구간 목록은 접고 펼치는 묶음과 개별 행으로 표시합니다. Shift 또는 Command/Ctrl 클릭으로 복수 선택하고 Command/Ctrl+G로 묶습니다. 기존 도로 묶음은 유지합니다.
- 행 앞 숫자는 등급 선택입니다. 묶인 도로의 등급은 함께 변경하며 실제 폭 정보 우선 규칙을 유지합니다.
- Delete, Backspace, D 또는 삭제 버튼으로 선택 도로를 생성 대상에서 제외합니다. 입력란·등급 선택 중에는 삭제 단축키를 처리하지 않습니다.
- excludedRoads에는 원본 editId만 저장합니다. generation-input의 모든 도로 원본은 보존합니다. 실제 도로 예약·건물 배치·가시성·원경 생성 전에 제외하고, 삭제한 도로 복원으로 다시 활성화합니다.
- 도로 변경은 적용/동네 만들기 전까지 초안입니다. 닫기/취소하면 저장하지 않습니다. 모든 원본 도로를 제외한 잘못된 입력은 생성 오류로 처리합니다.
- 묶음 표시를 접거나 펼치는 것은 목록 표시만 바꾸며 도로 형상은 바꾸지 않습니다. 단계가 여러 개인 중첩 폴더는 만들지 않습니다.
- 원본 class=busway는 기존 분류기에서 1차도로 기본값을 받을 수 있습니다. 도봉로 자료에 해당 구간이 존재함을 확인했습니다. 실제 버스 차로를 잘못 지우지 않도록 자동 삭제는 하지 않습니다. 사진만으로 해당 선의 정확한 ID를 확정하지 않았습니다.
